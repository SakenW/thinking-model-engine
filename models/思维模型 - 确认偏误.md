# 确认偏误 (Confirmation Bias)

## 概述

**只注意、只相信、只记得支持自己观点的信息**，自动忽略或贬低反对证据。它是人类最顽固的认知偏误之一——先有结论，再找理由，是大脑的默认路径。**几乎所有争论的根源都是双方都在做确认偏误。**

一句话版本：**你不是在找真相，你是在找支持自己的证据。**

## 核心机制

三个层面同时运作：
- **选择性注意**：只看到想看的（支持自己的信息自动跳出来）
- **选择性记忆**：记得住支持的，忘得掉反对的
- **动机性推理**：反对证据被加工成"不算数"（来源不可信/方法有问题/特殊案例）

## 不同领域的应用

| 场景 | 确认偏误的表现 | 应对 |
|------|--------------|------|
| **投资** | 只读看多研报，忽略利空信号 | 强制读空头报告，设"证伪条件" |
| **产品决策** | 只收集用户好评 | 专门访谈流失用户 |
| **团队讨论** | 老板倾向的方案，全员找论据 | 指定红队/反对者角色 |
| **自我认知** | "我做得没错，是环境问题" | 记录失败案例做复盘 |
| **信息摄入** | 只看同立场内容源 | 主动订阅对立观点 |

## 工作示例

> **投资自检：**
>
> - 持有某标的，满眼都是利好新闻
> - 利空消息出现时："这个影响不大 / 是暂时的 / 市场没看懂"
> - 解法：买入时**提前写下**"什么条件下我会卖"——写下来的条件，比临场判断难糊弄

## 使用步骤（对抗确认偏误）

1. **主动找反证** — 问"什么证据会证明我错了？"然后真的去找
2. **红队机制** — 重要决策指定一人专门唱反调（或自己用对抗式审查）
3. **预注册判断** — 先写下结论和预测，再收集数据；事后诸葛亮最容易骗自己
4. **贝叶斯更新** — 明确写下先验，强制评估每个证据在"反面假设"下出现的概率
5. **记录被打脸案例** — 复盘"我以为对但错了"的时刻，校准自信

## 注意事项

- **越聪明越危险** — 智力高的人更擅长为错误观点辩护
- **信息茧房是放大器** — 算法推流 + 同温层 = 确认偏误的舒适区
- **和贝叶斯思维是反的** — 贝叶斯要求考虑全部证据，确认偏误只喂一半
- **无法根除，只能对抗** — 对抗手段是流程性的（红队、预注册），不是意志力

## 变体/相关模型

- **贝叶斯思维**：确认偏误的数学解药
- **达克效应**：不知道自己不知道，和确认偏误互相强化
- **合取谬误**：故事越顺越信，同属"先结论后论证"
- **框架效应**：表述引导立场，立场又触发确认偏误
- **沉没成本**：为已投入辩护，是确认偏误的动机来源之一

## 适用场景

- 投资与研究决策
- 产品/项目评审
- 团队决策与讨论
- 信息摄入管理（破信息茧房）
- 自我复盘与成长

```markdown
- [ ] 这个结论是我先有立场后找的理由，还是先看证据后下的判断？
```
