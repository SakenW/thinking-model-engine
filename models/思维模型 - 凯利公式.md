# 凯利公式 (Kelly Criterion)

## 概述

1956 年贝尔实验室的 John L. Kelly Jr. 在论文《A New Interpretation of Information Rate》中提出，最初用于通信噪声中的信息传输研究，后被博彩和投资界广泛采用。核心思想：**在已知胜率和赔率时，算出单次下注应占资金的比例，使长期资金增长率最大化，同时理论上永不破产。**

一句话版本：**你的信息优势有多大，就下多大注。** 优势越大，注码越大；没有优势，一分钱都不下。

## 核心公式

```
f* = (b × p - q) / b = p - q / b
```

- **f\***：最优下注比例（占当前总资金的比例）
- **b**：净赔率（赢一局赢 b 倍本金；"1赔1"时 b = 1）
- **p**：胜率
- **q**：败率 = 1 - p

**直觉推导**：凯利公式本质是最大化对数财富期望 E[log(W)]。对数效用下，每次下注的期望对数增长 = p·log(1+bf) + q·log(1-f)，对 f 求导取零即得上述公式。对数增长对应**长期复合增长率**，这正是复利的数学表达。

**快速判断**：
- b·p - q < 0（期望为负）→ f* 为负 → **不下注**
- b·p - q = 0（公平游戏）→ f* = 0 → 不下注，长期必归零
- b·p - q > 0 → 按比例下注

## 不同领域的应用

| 领域 | 怎么用 | 示例 |
|------|--------|------|
| **体育博彩** | 找"价值注"：赔率隐含概率 < 你估算的真实概率 | 真实胜率 60%，赔率 1赔1（隐含 50%）→ 有优势，按公式下注 |
| **股票投资** | 为有正期望的策略定仓位上限 | 策略年胜率 55%、平均盈亏比 1.5 → 代入公式得建议仓位 |
| **扑克/棋牌** | 资金管理，避免单局过载 | 锦标赛按筹码优势动态调整投入 |
| **创业/资源配置** | 类比：确定性优势明确的投入可以加大 | 已验证的商业模式扩张 vs 全新赌注，前者可用更高凯利比例 |

## 工作示例

> **抛硬币游戏，55% 胜率，1赔1：**
>
> f* = (1 × 0.55 - 0.45) / 1 = **0.10** → 每次下注 10% 资金
>
> **同样的游戏，60% 胜率：**
>
> f* = (1 × 0.60 - 0.40) / 1 = **0.20** → 每次下注 20% 资金
>
> **10% 的胜率优势，让建议注码翻倍** —— 凯利对 p 极其敏感。

## 使用步骤

1. **诚实估计胜率 p** — 用历史数据，别用感觉；p 是最容易自欺的变量
2. **确认赔率 b** — 含手续费/抽水的实际净赔率
3. **代入公式** f* = p - q/b
4. **打折执行** — 实践建议乘以 0.5（半凯利）或 0.25，尤其参数不确定时
5. **定期重估** — p 和 b 会随时间变化，仓位要跟着更新

## 注意事项

- **参数敏感是最大陷阱**：p 估计偏差 5 个百分点，建议仓位可能差一倍。估计越不准，越该用分数凯利
- **全凯利回撤巨大**：长期增长最优 ≠ 短期体验最优，全凯利策略常伴随 30-50% 的回撤，多数人中途拿不住
- **公式前提**：已知概率分布、独立重复下注、可长期重复。现实投资既非独立也非同分布，只能当近似参考
- **"永不破产"是理论性质**：实际有最小下注单位、资金不可无限细分，小资金账户仍可能实际清零
- **连续时间版本**（Merton 分数）：对对数正态资产，f* = (μ - r) / σ²，波动率越大，最优仓位越低——和直觉一致
- **凯利不是致富公式，是生存公式**：它防的是"赢了很多次后一次梭哈归零"

## 变体/相关模型

- **分数凯利 (Fractional Kelly)**：全凯利 × 1/2 或 1/4，牺牲部分增长换大幅降低回撤
- **对数效用函数**：凯利公式的效用论基础（期望效用理论）
- **均值-方差框架 (Markowitz)**：现代组合理论，与凯利互补的另一种仓位思路
- **安全边际**：格雷厄姆/巴菲特式保守——"即使估计错了也够"，和分数凯利精神一致
- **期望值计算**：凯利的前提——先有正期望，才谈得上注码
- **赌徒破产问题**：无优势时长期下注必破产的数学证明
- **反脆弱**：控制下行、保留上行的仓位哲学，与凯利的生存优先一致

## 适用场景

- 体育竞猜/博彩的注码管理
- 投资策略的仓位上限设定
- 任何"重复下注 + 已知胜率赔率"的决策
- 对赌协议、项目投入比例的类比参考
- 个人精力/资源分配（优势明确的领域加大投入）
