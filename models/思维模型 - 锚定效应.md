# 锚定效应 (Anchoring Effect)

## 概述

决策时**第一个出现的数字/信息会成为参照系**，后续判断被它"锚定"，即使这个锚完全无关。卡尼曼与特沃斯基的经典发现：先看大数字，后续估计就偏高；先看小数字，就偏低。**锚可以是任何东西：原价、别人出的价、第一个方案、甚至随机数。**

一句话版本：**先入为主的数字，会绑架你的判断。**

## 核心机制

```
判断 ≈ 锚点 + 有限调整（调整总是不够的）
```

- 锚定是**自动发生的**，不经过意识，即使知道它在也不一定能摆脱
- 调整不足：人们从锚点出发做调整，但几乎总是调不到位

## 不同领域的应用

| 场景 | 锚点怎么起作用 | 应对 |
|------|--------------|------|
| **谈判** | 先出价的人设锚，对方在锚附近还价 | 做先出价的人，或事先定好自己的锚 |
| **购物** | "原价 999，现价 499" 让你觉得赚了 | 问自己：这货值多少？而不是比原价便宜多少 |
| **定价** | 菜单第一道菜定消费水平 | 你是卖家就主动设锚，买家就忽略它 |
| **估值** | 融资先看对标公司估值 | 独立算自己的数，再参考市场 |
| **KPI 设定** | 去年数字是天然锚 | 从目标反推，不从历史顺推 |

## 工作示例

> **谈判：**
>
> - 你心里价位 80 万，对方开口 40 万 → 你的还价被锚在 40 万附近，最终 60 万成交，你觉得还行
> - 如果你先开口 120 万 → 对方还价空间从 120 往下走，同样让步幅度，最终可能 90 万
> - **先出价者的锚，往往就是成交价的锚**

## 使用步骤（防锚自检）

1. **识别锚** — 眼前这个数字/信息是我自己算出来的，还是别人塞给我的？
2. **独立估值** — 不看任何参照，先写下自己的判断（用期望值/决策矩阵）
3. **再接触锚** — 拿自己的数去比较，而不是拿锚来调整
4. **警惕"合理化的锚"** — 对标公司、历史价格、行业惯例，都可能是精心设置的锚

## 注意事项

- **知道锚定效应 ≠ 免疫** — 卡尼曼自己都承认摆脱不了
- **锚定不是只有数字** — 第一个方案、第一个版本、第一印象都是锚
- **组合拳**：锚定常和框架效应、心理账户一起出现
- **对抗方式不是"更努力调整"** — 是"换个参照系"或"先独立判断"

## 变体/相关模型

- **框架效应**：表述方式影响判断（同族）
- **前景理论**：参考点依赖——锚就是参考点的来源
- **心理账户**：钱被锚在不同账户里价值不同
- **可得性启发**：另一个系统性判断偏差

## 适用场景

- 谈判与报价
- 定价与估值
- 预算与 KPI 设定
- 消费决策（促销价陷阱）
- 任何"先看到数字再判断"的场景

## 自检清单

```markdown
- [ ] 我的判断基准是自己算的，还是别人给的？
- [ ] 如果第一个数字完全不同，我的结论会变吗？→ 会变说明被锚了
- [ ] 我有没有先写下独立判断再比较？
- [ ] 这个"参考价/对标"是事实还是话术？
```
