# 幸存者偏差 (Survivorship Bias)

## 概述

**只看到"活下来"的样本，忽略"死掉"的样本**，导致对成功概率和规律的错误判断。二战时统计学家沃尔德发现：返航飞机的弹孔集中在机翼，于是有人建议加固机翼——但正确的做法是加固**没有弹孔的发动机和驾驶舱**，因为被打中那里的飞机根本没飞回来。**你看到的样本，是被筛选过的。**

一句话版本：**看不见的失败者，才是真相的大头。**

## 核心机制

```
观察样本 = 幸存者（被筛选后剩下的）
被忽略的 = 阵亡者（不在视野里）

用幸存者推规律 → 高估成功率、误读成功原因
```

## 不同领域的应用

| 场景 | 幸存者偏差的表现 | 真相 |
|------|----------------|------|
| **成功学** | 大佬都辍学/都熬夜/都激进 | 辍学创业的失败者更多，只是没人写书 |
| **基金业绩** | 榜单上的明星基金 | 亏到清盘的基金已不在榜单 |
| **创业** | 融资新闻满天飞 | 死掉的公司不开发布会 |
| **二战飞机** | 返航机翼弹孔多 | 发动机中弹的没回来，才该加固 |
| **社交媒体** | 人人光鲜 | 展示的是筛选后的生活 |
| **医疗** | 偏方"治好"了某人 | 用偏方没好的人不会出来说 |

## 工作示例

> **看行业成功率：**
>
> - 媒体：这家公司 3 年做到上市
> - 幸存者偏差视角：同一赛道同期创业 1000 家，998 家没上市，还有 700 家已注销
> - 正确的学习对象不是"上市的 2 家做了什么"，而是"998 家在哪一步死的"——死亡原因才是可复用的规律

## 使用步骤

1. **问：样本从哪来？** — 我看到的是全部，还是被筛选后的？
2. **找看不见的样本** — 失败者、退出的、没上榜的、没发声的
3. **对比死亡率** — 成功概率 = 成功者 ÷ 全体尝试者，不是成功者 ÷ 成功者
4. **提炼可复制规律** — 幸存者的特质里，哪些是成功原因、哪些只是幸存者共同点（甚至有可能是坑）

## 注意事项

- **成功者画像可能是幸存者共同点，不是成功原因** — 大佬都每天工作 16 小时，但每天工作 16 小时的人大多没成功
- **别用"榜样的力量"代替统计** — 榜样激励可以，但别据此规划人生
- **数据要问"分母"** — 任何成功率/收益率，先问分母是什么
- **反过来说**：做产品/内容时主动看竞品的"尸体"，比研究头部更有价值

## 变体/相关模型

- **贝叶斯思维**：幸存者偏差 = 忘了分母的先验错误
- **可达性启发**：幸存者案例更容易被想起，进一步放大偏差
- **达克效应**：幸存者偏差让失败者误以为自己也行
- **均值回归**：幸存者往往处于运气高点，之后回归
- **能力圈**：看清样本范围，才知道自己能不能复制

## 适用场景

- 研究行业/赛道/策略的成功率
- 分析竞品与对标
- 投资（基金业绩、策略回测）
- 个人规划（要不要复制某条路径）
- 数据解读（任何比率类结论）

## 自检清单

```markdown
- [ ] 我的样本是全体，还是筛选后的幸存者？
- [ ] 分母是什么？成功者占尝试者的比例是多少？
- [ ] 失败者的数据我能在哪找到？（而不是"没人说"）
- [ ] 幸存者的共性里，哪些是原因、哪些是噪声、哪些其实是坑？
```
