# 赌徒谬误 (Gambler's Fallacy)

## 概述

认为**独立随机事件存在"补偿"**的错误思维：轮盘连续出了 10 次红，就觉得"下次该出黑了"。真相是：独立事件**没有记忆**，硬币不知道它已经抛了几次正面，下次正反概率依然是 50/50。

一句话版本：**运气不欠你债。**

## 核心机制

```
P(下次) ≠ f(之前的结果)   ← 独立事件的定义
```

- 独立事件：每次结果与历史无关（硬币、轮盘、骰子、独立抽样）
- 非独立事件：结果受历史影响（体温、库存、情绪、均值回归系统）
- 混淆两者 = 赌徒谬误（对独立事件）或 热手谬误（对非独立事件硬套独立性）

**配套现象——热手谬误 (Hot Hand Fallacy)**：反过来，连续赢了几把就觉得"手气正热"、加大注码。同样基于错误记忆：短期序列在人类眼里总像"有规律"，其实只是随机波动。

## 工作示例

> **错误：** 连亏 7 单了，下把加大仓位"总该回本了" → 如果每单独立，连亏 7 单的概率已经发生，但下一单依然是原来的胜率
>
> **正确：** 连亏说明的是"你的胜率估计可能错了"或"样本太小"，该做的是重估概率（贝叶斯），不是加注（凯利公式会告诉你：概率没变，仓位就不该变）

## 使用步骤（防谬误自检）

1. **问：这件事独立吗？** — 结果会受上次影响吗？不会 → 别用历史做赌注
2. **问：我是在"等补偿"吗？** — 是 → 提醒自己独立事件无记忆
3. **问：样本够大吗？** — 连输 7 次在 55% 胜率下并不罕见，别急着改策略
4. **把"该回本了"翻译成数学** — 那是期望值 + 凯利，不是运气

## 注意事项

- **和均值回归区分**：均值回归只适用于"有内在机制"的系统（身高、业绩回归均值），不适用于独立随机事件——轮盘没有"均值"要回归
- **赌场靠这个赚钱**：庄家优势 + 赌徒的"翻本"心理
- **连续出现 ≠ 规律**：任何随机序列里都有"看起来有规律"的片段

## 变体/相关模型

- **期望值计算**：EV 为负时，任何注码策略都是输
- **凯利公式**：正确的注码方法——和赌徒谬误正好相反（概率不变，仓位就不变）
- **贝叶斯思维**：连续异常结果真正该触发的是"更新先验"，不是"加大赌注"
- **均值回归**：常被误用的"补偿"概念
- **合取谬误**：同样源于对随机性的直觉误判

## 适用场景

- 博彩/股票连续亏损时的心理管理
- 任何"连续出现后觉得该反转了"的时刻
- 数据观察中的随机性判断
- 团队士气管理（连败时别用"该赢了"打鸡血）

## 自检清单

```markdown
- [ ] 这个事件真的独立吗？（有没有机制让它依赖历史？）
- [ ] 我有没有在"等补偿"？→ 独立事件没有补偿
- [ ] 连亏/连赢的样本量够判断吗？（小样本全是噪声）
- [ ] 我的下一步是基于概率，还是基于情绪？
```
