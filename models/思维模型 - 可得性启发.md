# 可得性启发 (Availability Heuristic)

## 概述

**越容易想起的事，越被高估其发生频率和重要性。** 大脑用"回忆的轻松程度"代替"真实统计概率"——因为空难新闻铺天盖地，人们高估空难风险；因为明星暴富故事刷屏，人们高估创业成功率。**记忆的可得性 ≠ 现实的概率。**

一句话版本：**你以为是概率判断，其实是记忆检索。**

## 核心机制

```
判断频率 ≈ 回忆难度（越容易想起 → 觉得越常见）
```

哪些事更容易被想起：
- **最近发生的**（近因效应）
- **情绪强烈的**（恐惧、震撼、愤怒）
- **媒体反复报道的**（算法推流、新闻轰炸）
- **画面感强的**（具体案例 > 抽象统计）

## 不同领域的应用

| 场景 | 可得性偏差的表现 | 真相 |
|------|----------------|------|
| **风险判断** | 怕坐飞机、不怕开车 | 车祸死亡率远高于空难 |
| **投资** | 牛市顶部人人觉得"稳赚" | 因为身边人都在赚钱（被想起的样本） |
| **产品决策** | 用户提的最多的需求优先做 | 少数激动用户的声音 ≠ 沉默多数 |
| **内容选题** | 追最近刷屏的题材 | 刷屏 = 可得性高，不等于市场需求大 |
| **招聘** | 面试官被最后一位候选人的表现带偏 | 近因效应污染整体判断 |

## 工作示例

> **投资中的可得性陷阱：**
>
> - 牛市中后期：朋友圈全是晒收益 → "市场稳赚"的可得性极高 → 高位加仓
> - 熊市底部：全是亏钱哀嚎 → "股市是赌场"的可得性极高 → 底部割肉
> - **市场情绪的本质，就是群体可得性偏差的钟摆**
>
> 解法：把"感觉"换成统计数据——估值分位、成交量、历史胜率，用数字代替记忆。

## 使用步骤（防偏差自检）

1. **识别触发** — 这个判断是来自"我想起了一些例子"，还是来自"统计数据"？
2. **找统计数字** — 用真实频率替换记忆可得性
3. **扩大样本** — 别用最近的 3 个例子代表全部 1000 个
4. **反过来想** — 如果我没看过那条新闻，我的判断会变吗？
5. **延迟决策** — 情绪强烈的信息（恐怖、暴富）会拉高可得性，先放 24 小时

## 注意事项

- **媒体和算法是放大器** — 它们设计出来就是让你"容易想起"某些事
- **具体案例永远打败统计** — 一个生动的故事 > 一张数据表，所以要主动用数据武装
- **和幸存者偏差同族** — 幸存者案例可得性最高，两偏差叠加威力翻倍
- **重要决策一律查数** — 涉及钱、健康、安全的判断，禁止用"印象"

## 变体/相关模型

- **幸存者偏差**：幸存者案例天然高可得性，两者叠加
- **锚定效应**：先见到的信息也通过可得性影响判断
- **近因效应**：最近发生的事可得性最高
- **框架效应**：表述方式影响哪些信息被突出、被想起
- **贝叶斯思维**：用证据更新代替印象更新

## 适用场景

- 风险与概率判断（出行、健康、投资）
- 需求优先级排序
- 市场情绪识别（牛熊判断）
- 新闻信息消费管理
- 任何"凭印象拍概率"的时刻

## 自检清单

```markdown
- [ ] 我的概率判断有统计数据支撑吗？还是凭印象？
- [ ] 最近 24 小时我是不是刚看过相关新闻/案例？
- [ ] 我能说出相反的例子吗？（想不出来 = 可得性偏误在工作）
- [ ] 如果从没听过最近的案例，我的判断会变吗？
```
